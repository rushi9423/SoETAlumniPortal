# 🎓 SOET Alumni Portal

A modern, responsive **Alumni Portal UI Prototype** designed for the School of Engineering and Technology (SOET), MGM University. The goal of this project is to provide a clean and intuitive interface that connects students, alumni, faculty, and administrators on a single platform.

## 📖 Overview

The Alumni Portal is designed to strengthen the relationship between alumni and the institution by providing a centralized platform for networking, mentorship, career opportunities, and community engagement.

This repository currently contains the **frontend prototype** of the platform, showcasing the intended user interface and experience.

## 🚀 Running the Project

This project is a static frontend prototype.

Clone the repository:

```bash
git clone https://github.com/deoreparth700-design/Alumni-Portal.git
```

Open the project folder:

```bash
cd Alumni-Portal
```

Launch the application by opening:

```
index.html
```

in any modern web browser.

No installation or build process is required.
